## Team names

Use these exact names for every month:

```text
team_x
team_y
team_z
team_xyz
```

Membership changes at the start of every month. Each team has three seats and produces two case studies per month.

## Individual contribution folders

Each named contributor has a GitHub-username folder under their primary track. Every contributor has `W-01` through `W-24`; each week contains a Markdown progress file. The team roster determines which team a contributor works with for that month.

The roster currently contains 11 named people. `TBD_MEMBER_12` is a temporary seat and must be replaced when the twelfth person is supplied.
