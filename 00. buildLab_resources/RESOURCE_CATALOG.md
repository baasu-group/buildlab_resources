# Validated learning resource catalog

**Validation date:** 2026-08-10

Choose one primary path and use videos to unblock practice rather than collecting dozens of courses.

## Labels

- **Roadmap:** free role/skill sequence on roadmap.sh.
- **Official:** vendor or maintainer documentation; use it to verify current behavior.
- **YouTube:** free video or channel; availability can change.
- **Udemy — free when validated:** the page showed a free course at validation time. Udemy pricing can change by country and over time, so check before enrolling.

## Validation rule for mentors

At the start of each quarter, open every external link used in the next 12 weeks and record:

```text
date_checked:
url:
title:
provider:
free_or_paid:
language:
last_updated_or_published:
replacement_if_unavailable:
```

If a resource is unavailable, replace it with an official documentation page, a current channel video, or a new free course covering the same learning objective. Do not change the learning outcome just because a video changed.
