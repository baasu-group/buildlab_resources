# AWS learning path

Use AWS only after the application runs locally. Cloud learning is about architecture, security, reliability, and cost—not clicking through services without a product need.

## Six-month sequence

| Month | Focus | Evidence |
| --- | --- | --- |
| 1 | Regions, accounts, IAM, shared responsibility, networking vocabulary | Draw the request path and least-privilege access plan |
| 2 | VPC basics, compute, storage, managed database concepts | Compare two deployment options and their costs/risks |
| 3 | Deploy a development or staging slice | Document environment variables, DNS, and rollback |
| 4 | Logs, metrics, backups, scaling, and security groups | Health check and incident checklist |
| 5 | Infrastructure as code and CI/CD integration | Repeatable environment change in a safe sandbox |
| 6 | Release readiness and cost review | Architecture diagram, runbook, and monthly cost estimate |
