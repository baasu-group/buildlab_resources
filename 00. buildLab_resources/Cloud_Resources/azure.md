# Azure learning path

Azure is an alternative cloud track. The internship should standardize on one cloud for the shared release, while learners may compare equivalent services here.

## Six-month sequence

| Month | Focus | Evidence |
| --- | --- | --- |
| 1 | Tenants, subscriptions, resource groups, Entra ID, shared responsibility | Identity and ownership map |
| 2 | Virtual networks, App Service/Container Apps, storage, managed database concepts | Service-selection comparison |
| 3 | Staging deployment and configuration | Repeatable deployment notes |
| 4 | Monitor, logs, backups, scaling, and network security | Health and incident checklist |
| 5 | Infrastructure as code and pipeline integration | Safe, reviewable infrastructure change |
| 6 | Release and cost review | Architecture diagram, runbook, cost estimate |
